### Dev Server 崩溃问题与解决
- 问题：`vite dev` 优化依赖时需删除 `.vite/deps_temp_*`（285 文件），被 WorkBuddy 安全删除保护拦截（阈值 50），进程崩溃，页面空白
- 现象：HTML 正常返回但所有 JS/CSS 模块返回 0 字节，Vite 进程已死
- 解决：改用 `npm run build && npm run preview`（端口 4173），不涉及依赖优化，正常工作
- 教训：本环境预览前端项目一律用 preview，不用 dev

### Cloudflare Pages 构建报错修复
- 问题：Cloudflare 要求 Vite >= 6.0.0，项目用的是 5.4.21
- 修复：升级 vite@^6.0.0 + @vitejs/plugin-vue@latest + vite-plugin-pwa@latest
- 构建通过（Vite 6.4.3 + PWA v1.3.0），已提交 commit ae5dcc3
- 用户需重新 git push 触发 Cloudflare 重新构建

### 用户部署类型错误（关键问题）
- 现象：访问 `lihf.pages.dev` 无内容
- 根因：用户创建的是 Cloudflare Worker 项目（不是 Pages 项目），Deploy command 是 `npx wrangler deploy`，Workers URL 开关未启用
- Workers 项目没有 `*.pages.dev` URL，只有 `*.workers.dev`（且用户没启用）
- 修复：删除 Worker 项目，重新创建 Pages 项目（必须选 Pages 标签，不是 Worker）
